# プロダクト名
WalkGuessr
> 一言でどんなプロダクトか（30字以内）
道中のお題の景色を歩きながら探して写真を撮る

## 課題
観光や通学・通勤で徒歩移動する時間は、目的地に着くまでの「ただの移動」になりがちで、スマホをただ眺めて過ごしてしまう人が多いです。特に京都のような観光地では、有名スポット以外にも道中に魅力的な景色がたくさんあるのに、目的地までまっすぐ向かうだけで見過ごされてしまいます。

- 徒歩移動中の暇な時間をただ消費してしまっている人
- 観光地を歩いていても、決まったスポット以外の景色に目を向ける機会がない人
- 一人での散策や移動はつまらないが、友達を誘って一緒に何かするほどの予定でもない人

WalkGuessrは、目的地までの寄り道そのものをゲームにすることで、移動時間を「探す・撮る・当てる」という能動的な体験に変え、ひとりでも、友達とオンラインで対戦しながらでも楽しめる形で解決します。

## 解決方法
- 目的地までの道中に「見本の写真」を出題し、そっくりの景色を実際に歩いて探して撮影してもらう
- 撮影地点と見本の地点とのGPS距離を自動採点し、近い場所で撮れるほど高得点になるゲーム性を付与
- 「グループで対戦」機能で、友達と同じお題スポットをリアルタイムに競い合える

## 使用技術
| 領域 | 技術 |
| --- | --- |
| フロントエンド | React 19 + TypeScript + Vite／Leaflet.js + OpenStreetMap（地図・ルート表示） |
| バックエンド | なし（サーバーレスの静的サイト）。対戦モードはFirebase Realtime Databaseでブラウザ間を直接同期 |
| その他 | Geolocation API・DeviceOrientationEvent（現在地・コンパス方位の取得）、Vercel（ホスティング） |

## 動かし方
```bash
npm install
npm run dev
```
ブラウザで `http://localhost:5173` を開いてください。
